# GARAGE Sala de Ensayo — sitio web

Sitio estático (HTML + CSS + JS), sin instalaciones.

## Ver en tu computadora (Visual Studio Code)
1. Abre la carpeta en VS Code (Archivo > Abrir carpeta).
2. Instala la extensión **Live Server** (Ritwick Dey).
3. Clic derecho en `index.html` > **Open with Live Server**.
(También puedes hacer doble clic en `index.html` y se abre en el navegador.)

## Qué cambiar
- Teléfono, correo y Facebook: bloque `CONFIG` al inicio de `js/script.js`.
- Colores: bloque `:root` al inicio de `css/styles.css`.
- Textos y equipos: `index.html`.
- Logo: reemplaza los archivos de `assets/`.

## Subir al repositorio
```
git add -A
git commit -m "Rediseño: GARAGE Sala de Ensayo"
git push
```
